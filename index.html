☁️ Synchronisation entre appareils

Retrouvez les mêmes données sur votre téléphone et votre ordinateur. Elles sont enregistrées dans un « gist » secret de votre compte GitHub (gratuit, aucun autre service).

Comment obtenir le jeton ?
  1. Ouvrez cette page GitHub (connectez-vous si besoin).
  2. Laissez uniquement la case gist cochée, choisissez une expiration (ou « No expiration »), puis « Generate token ».
  3. Copiez le jeton et collez-le ici. Sur l'autre appareil, collez le même jeton.

Le jeton ne donne accès qu'à vos gists, pas à vos dépôts. Il reste uniquement sur cet appareil. Un gist secret n'est pas listé mais reste accessible à quiconque en connaît l'adresse : n'y mettez rien que vous jugeriez trop sensible dans les notes.

La synchronisation se fait automatiquement à chaque changement et à l'ouverture de l'app.
