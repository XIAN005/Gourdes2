Synchronisation entre appareils

Retrouvez les mêmes données sur votre téléphone et votre ordinateur. Elles sont chiffrées puis enregistrées dans un gist de votre compte GitHub.

La synchronisation est désormais chiffrée. Choisissez une phrase secrète pour la réactiver.

Vos données sont chiffrées avant l'envoi : sans cette phrase, personne ne peut les lire, pas même GitHub. Elle ne peut pas être récupérée si vous l'oubliez. Utilisez la même sur chaque appareil.

Comment obtenir le jeton
  1. Ouvrez cette page GitHub et connectez-vous si besoin.
  2. Laissez uniquement la case « gist » cochée, choisissez une expiration, puis générez le jeton.
  3. Collez-le ici. Sur l'autre appareil, collez le même jeton.

Le jeton ne donne accès qu'à vos gists, pas à vos dépôts. Le contenu du gist est chiffré (AES-256) : sans votre phrase secrète, il est illisible.

La synchronisation se fait à chaque changement et à l'ouverture de l'application.

Confidentialité

Le code PIN est actif. L'application se verrouille après une minute passée en arrière-plan.

Le code PIN verrouille l'écran de l'application. Les données restent enregistrées sur l'appareil : il ne remplace pas le verrouillage de votre téléphone.

Mes données

Vos données sont enregistrées sur cet appareil. Faites une sauvegarde de temps en temps (la clé API n'y est pas incluse).
